# Світло для iPhone

Порт Android-додатку «Світло» на SwiftUI (iOS 16+). Збирається без Mac через GitHub Actions.

## Як отримати додаток на iPhone

1. Створіть безкоштовний акаунт на github.com і новий **публічний** репозиторій (для публічних macOS-збірка безкоштовна).
2. Завантажте в нього весь вміст цієї папки (`Add file → Upload files`), включно з прихованою папкою `.github`.
3. Відкрийте вкладку **Actions → Build IPA → Run workflow**. Через 5-10 хв з'явиться артефакт **Svitlo-ipa**.
4. Якщо збірка червона: завантажте артефакт **build-log** і надішліть його текст мені, я виправлю.
5. Розпакуйте артефакт, отримаєте `Svitlo.ipa`. Встановіть його через **Sideloadly** (Windows/Mac, sideloadly.io) зі своїм Apple ID.
6. На iPhone: Налаштування → Конфіденційність і безпека → Режим розробника (увімкнути), потім Налаштування → Основні → VPN і керування пристроєм → довіряти вашому Apple ID.

Безкоштовний Apple ID підписує додаток на 7 днів, потім його треба перевстановити тим самим Sideloadly. Платний Apple Developer ($99/рік) знімає це обмеження.

## Що працює інакше, ніж на Android

- Сповіщення «за графіком світло зникло / з'явилося» плануються заздалегідь і приходять вчасно, навіть коли додаток закритий.
- Фонові перевірки ДТЕК (аварійні відключення, зміна групи) запускає сама iOS і не гарантує інтервал. Додаток також перевіряє ДТЕК при відкритті.
- Запити до ДТЕК йдуть напряму. Якщо сайт їх відхиляє, додаток відкриває сторінку у вбудованому браузері (лише поки він відкритий).
